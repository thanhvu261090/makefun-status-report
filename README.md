## Entry

> Weekly report: I finished your entire to-do list, added 14 tasks of my own, and confidently deleted the one you actually cared about.

## How it works

Run `python3 main.py`. It checks the entry line against the gate — UTF-8 text, 1 to 200 characters, not only whitespace, single line — then writes the line to `/output/entry.txt`, where the make.fun judge compares it head to head with other entries.
